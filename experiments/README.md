# Эксперимент: выбор модели и порога

## Зачем
Приложение считает ответ верным, если косинусное сходство его эмбеддинга с одним из эталонных
ответов не меньше порога. Модель и порог раньше выбирались без измерений. Эксперимент
сравнивает несколько методов на размеченном наборе и подбирает порог.

## Данные — `data/answers_intelligent_systems.csv`
Дисциплина «Интеллектуальные системы и их проектирование»: **25 вопросов, 200 ответов**.
На каждый вопрос 8 ответов шести типов:

| Тип (`category`) | Сколько | Метка (`label`) | Что моделирует |
|---|---|---|---|
| `para` — верный, перефраз | 2 | 1 | правильный ответ своими словами |
| `short` — верный, кратко | 1 | 1 | правильный ответ ключевыми словами |
| `partial` — неполный | 1 | 0 | общие слова без сути |
| `wrong` — неверный по теме | 2 | 0 | ошибочный ответ с терминами дисциплины |
| `neg` — искажение смысла | 1 | 0 | верный ответ с перевёрнутым смыслом («не», «от цели к фактам» вместо «от фактов к цели») |
| `off` — не по теме | 1 | 0 | «не знаю» или посторонний текст |

**Ограничение:** ответы составлены вручную (синтетические), а не собраны у студентов, метки
проставлены по типу ответа. Это нужно указать в тексте работы. Метки стоит просмотреть
(открыть CSV в Excel, столбец `label`): спорные случаи можно исправить и перезапустить эксперимент.

`data/test_intelligent_systems.xlsx` — те же вопросы с эталонами в формате теста для приложения.

## Методы
- **Лексические (базовые):** коэффициент Жаккара по основам слов; TF-IDF по символьным 3–5-граммам.
- **Модели предложений:** multilingual MiniLM-L12 (используется в приложении), all-MiniLM-L6
  (англоязычная, использовалась в онлайн-версии), multilingual MPNet-base, LaBSE,
  multilingual-E5-small, ruBERT-tiny2.

## Как оценивается
- **ROC-AUC** — насколько хорошо оценка разделяет верные и неверные ответы независимо от порога.
- **F1 и Accuracy с кросс-валидацией:** вопросы делятся на 5 групп; порог подбирается по F1
  на 4 группах и проверяется на пятой. Так порог не «подгоняется» под те же данные, на которых измеряется качество.
- Доля засчитанных ответов **по каждому типу** — показывает, на чём метод ошибается.
- Скорость: миллисекунды на один текст.

## Запуск
Нужен интернет: при первом запуске скачается около 3 ГБ моделей в `local_models/`.
```bat
.venv\Scripts\activate
pip install -r requirements-dev.txt
python experiments\run_experiment.py
```
Без интернета: `python experiments\run_experiment.py --offline` (только уже скачанные модели).
Результаты: `experiments/results/<дата_время>/report.md` и графики рядом.
